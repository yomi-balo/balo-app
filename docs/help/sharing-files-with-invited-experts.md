Have a brief, a spec or a screenshot that will help an expert prepare? Share it right from the
conversation, with a short note if you like. The expert gets a notification, and when your
conversation with them is open, the file and your note also appear as a message in the thread.
Otherwise they'll find the file waiting in Files.

## Share from the conversation

In a conversation with an invited expert, attach a file from the message box and add a note if
you'd like to explain it. The button names who you're sharing with, such as **Share with Priya**,
and the file lands in the thread for that expert.

## Choose who sees it

By default, a file goes to just this expert. If you sent your request to several experts, you can
widen a file to all of them, or pick specific experts. A request sent directly to one expert shares
with that expert only. Each expert sees only the files shared with them.

## Find everything in All files

Open **All files** on the request to see every file in one place, with who can see each one. From
there you can stop sharing a file whenever you like. On a request matched to several experts,
**Share with several experts** lets you upload a new file and choose who receives it.
