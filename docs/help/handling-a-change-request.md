Sometimes a client reviews your finished project and asks for changes instead of accepting. This
guide covers what you receive, how to work through it and how to send the project back.

## What you receive

You get an email with the client's note, word for word, and a notification in Balo that links to
the project. The project goes back to active, and the project page shows a banner with the note at
the top. If the client picked particular milestones, the banner names them. If you're part of an
agency, its owners and admins are also notified in Balo when a client requests changes.

## Tagged and untagged requests

A client can attach their feedback to specific milestones, or leave it general.

- **Tagged.** Each milestone the client picked moves back to in progress, and the client's note is
  quoted on it. Any milestone they didn't pick stays completed.
- **Untagged.** No milestones are reopened. Read the note, then reopen whatever needs work.

## Working through it

Do the work in the milestones that came back. If the note points to a milestone that is still
marked complete, choose **Move back to in progress** on it, make your changes, then complete it
again as usual. Wording fixes on a milestone are plain edits. If the feedback calls for new paid
scope, such as an added milestone or a different price, send it as a change order instead. The
client approves it first, and the new work has to be completed too before the project is ready to
go back. See [Proposing a change to a live project](/help/proposing-a-change-to-a-live-project).

## When the banner changes to "Changes made"

Once every milestone the client tagged is complete again, and every other milestone on the project
is complete too, the banner changes to **Changes made** and offers to send the project back to the
client. Until then, the project page keeps its **Mark project ready again** button, which stays
unavailable while any milestone is unfinished, and while a change is open on the project: a
client's request for a change, a draft you made from one, or a change you've sent and the client
hasn't decided. For an untagged request, the same button is there
and you choose when you're done.

## Marking the project ready again

Choose **Mark project ready again** and confirm. The client is told the project is ready for their
review again, and the review window starts over from that moment. The client can then accept the
project or ask for more changes.

## Repeated rounds

A client may go through more than one round. Every round is kept on the project, and the latest
one is always the one shown to you. When a project comes back for a second round or more, the
Balo team may check in with you and the client to help get it over the line.
