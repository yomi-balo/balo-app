# Turning a case into a project

If a case has grown into something bigger than its next consultation, you can turn it into a
project request — with its own written scope and a proposal to review — without losing anything
you and the expert have already built up in the case.

## Where to find it

Open the case and look in the top right of its header for **Convert to project**. It's there on
open and resolved cases alike, so you don't need to close anything first. Converting never
changes the case itself — it stays exactly as it is, open or resolved, and you can keep using it
as normal.

## The AI draft

As soon as the form opens, we read through the case's messages and consultation transcripts and
put together a first draft of the project description — what the problem is, what's already been
resolved in the case, what's left, and the likely scope. You'll see "Drafting a brief from your
case…" while it works, then the draft fills in a section at a time.

The title and any products from the case carry over automatically. Tags aren't carried over, but
the draft may suggest some for you to review.

If the case doesn't have enough history to draft from, we'll let you know and leave the
description blank for you to write yourself.

## Editing and redrafting

Everything the draft writes is yours to edit. If you'd rather start over, choose **Redraft from
case** — we'll ask you to confirm before replacing your edits with a fresh draft.

## Adding case files

You can attach files already shared in the case instead of uploading them again — each one is
copied into your request, so the original stays where it is. A file can't be added if it's over
5 MB or isn't a PDF, PNG, JPEG or WEBP; the picker marks those as unavailable and says why. Case
files count toward the same four-file limit as anything you upload directly.

## The link back

The request records the case it came from. You'll see "Linked to case" on the review step
before you send it, and again on the confirmation screen once it's sent.
